Issue faced: setting up env. variable i.e. (MONGODB_URL)

SOLUTION:
---------------------------------------------------------------------------------------------------------------
After adding code to components.data_ingestion.py file and then further 
adding code corresponding to the Data Ingestion phase in the to TRAINING PIPELINE.
---------------------------------------------------------------------------------------------------------------

Before running demo.py to test our entire data ingestion setupset in the pipeline,
we need to set-up the MONGODB CONNECTION URL first.
---------------------------------------------------------------------------------------------------------------

To SETUP the connection url (windows):
open (new) Powershell terminal i.e. PS and run below command:
---------------------------------------------------------------------------------------------------------------

setting environment variable : $env:MONGODB_URL = "mongodb+srv://<username>:<password>......"
checking if it's set or not  : echo $env:MONGODB_URL

--------------------------------------------------------------------------------------------------------------
for cmd, use the command below for a permanent change in the env. variable i.e. 
Set Globally for Windows User (Optional) and If you want the environment variable to persist across all sessions, use:

setx AWS_ACCESS_KEY_ID "abc"

---------------------------------------------------------------------------------------------------------------

now RUN demo.py in the v-env created to check if the pipeline runs well for the data-ingestion phase created.
---------------------------------------------------------------------------------------------------------------

also, add artifact folder created on running pipeline into GITIGNORE by simply adding (artifact/) to .gitignore 
so that it is untracked.
